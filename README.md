SAT Query is an AI-powered Vision-Language and Geospatial Intelligence platform designed to make complex satellite imagery and Earth-observation analysis accessible through natural-language queries.

Instead of requiring researchers to manually navigate multiple GIS tools, datasets, and analytical workflows, SAT Query allows users to ask questions in natural language and translates those questions into structured geospatial analysis workflows. The system can combine computer vision, remote sensing, GIS operations, spatial analysis, temporal reasoning, and multimodal satellite data to generate visual and quantitative results directly on an interactive map.

The platform is designed around a Question → Plan → Analyze → Verify → Explain workflow. It can identify the analytical operations required for a query, select appropriate tools and data sources, perform spatial or image-based analysis, and present the resulting evidence through maps, layers, measurements, and explanations.

Key capabilities include:

🛰️ Satellite Image Analysis — Analyze optical, multispectral, and SAR imagery.
🧠 Natural-Language Queries — Ask complex Earth-observation questions without manually constructing GIS workflows.
🗺️ Interactive Geospatial Visualization — Display satellite imagery, terrain, boundaries, roads, rivers, land-cover layers, analytical masks, and derived results.
📊 Remote-Sensing Analysis — Support analyses such as NDVI, NDWI, NDBI, vegetation monitoring, water detection, and land-cover assessment where the required data is available.
📍 Spatial Analysis — Perform buffering, intersections, proximity analysis, area calculations, polygonization, spatial filtering, and other GIS operations.
⏳ Temporal Change Detection — Compare imagery across different dates to identify environmental, agricultural, urban, and infrastructure changes.
📡 Optical + SAR Fusion — Combine evidence from different sensing modalities to improve the reliability of interpretations.
🌍 Terrain & Topographic Analysis — Support elevation, slope, aspect, contours, hillshade, and terrain-based analysis when suitable elevation data is available.
🔎 Evidence & Provenance — Track the datasets, models, transformations, and analytical operations contributing to an answer.
⚠️ Uncertainty & Validation — Identify model disagreement, data limitations, unsupported analyses, and situations where the available evidence is insufficient.
🌐 Data Discovery — Designed to retrieve relevant external geospatial datasets from authoritative sources when user-provided data is unavailable, while preserving source and provenance information.
🤖 AI-Orchestrated Workflows — Use AI for query interpretation, scientific planning, tool selection, and result synthesis while keeping deterministic GIS and mathematical operations within dedicated analytical modules.

The long-term goal of SAT Query is to evolve from a conventional satellite-image question-answering system into a general-purpose scientific reasoning and analysis environment for Earth observation—where a researcher can describe what they want to investigate rather than manually specifying how to perform every GIS operation.

SAT Query turns natural-language questions into reproducible, evidence-driven geospatial analysis workflows.
